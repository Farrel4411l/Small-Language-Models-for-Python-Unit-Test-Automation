Fase 1: Data Engineering Pipeline (Menjawab RQ1 & RO1)
Di fase ini, kita akan membuat skrip Python untuk otomatisasi pembuatan dataset.

Web Scraper / API Fetcher: Skrip untuk mengambil source code terkait payroll atau pajak dari repositori open-source (misal via GitHub API).
LLM Generator Script: Skrip Python yang memanggil API LLM komersial (seperti OpenAI GPT-4 atau Gemini) untuk membaca source code tersebut dan membuat unit test Python berbasis pytest yang memvalidasi aturan PPh 21.
Database Integration: Kita akan menulis kode menggunakan SQLAlchemy atau client library Supabase untuk menyimpan pasangan data (Source Code + Unit Test) ke dalam database relasional.
Data Exporter: Skrip untuk memfilter data yang sudah divalidasi dari database dan mengekspornya ke format .jsonl yang siap digunakan untuk training model.

Fase 2: SLM Fine-Tuning dengan QLoRA (Menjawab RQ3 & RO3)
Ini adalah inti dari penelitian AI Anda. Kita akan menggunakan ekosistem Hugging Face.

Environment Setup: Saya bisa memandu Anda mengatur WSL (Windows Subsystem for Linux), menginstal CUDA, dan mengatur virtual environment Python agar GPU Anda bisa digunakan secara maksimal.
Training Script: Kita akan menulis kode menggunakan library transformers, peft (Parameter-Efficient Fine-Tuning untuk LoRA), dan trl (Supervised Fine-tuning Trainer). Kodenya tidak akan sepanjang yang dibayangkan, biasanya sekitar 100-200 baris kode yang difokuskan pada manajemen memori (kuantisasi 4-bit) agar Llama-3 8B bisa berjalan di GPU consumer-grade.

Fase 3: Automated Evaluation Pipeline (Menjawab RQ2 & RO2)
Setelah model dilatih, kita perlu membuktikan bahwa ia pintar.

Inference Script: Skrip untuk memuat model lokal Anda dan memberinya prompt berisi kode payroll baru (yang belum pernah dilihatnya).
Auto-Tester: Skrip Python yang secara otomatis menyimpan output dari model lokal Anda menjadi file test_*.py, lalu menjalankan perintah pytest secara programatis via subprocess.
Metrics Calculator: Skrip untuk mencatat apakah tesnya berhasil (pass rate), gagal (fail), atau kode yang dihasilkan error secara sintaks (syntax error), lalu menyimpannya dalam bentuk tabel hasil evaluasi atau grafik.
